# 교직원 연수 등록부 · GAS 단독 설치 (v5.1.0)

Vercel, 별도 서버, 별도 DB 없이 각 학교 담당자의 GAS/Google Drive에서 실행합니다.

## 새 학교에 설치

1. GitHub 최신 릴리스의 `TeacherSign-GAS.zip`을 내려받아 압축을 풉니다.
2. 학교 담당자의 Google 계정으로 https://script.google.com 에서 **새 프로젝트**를 만듭니다. 기본 `Code.gs` 내용 전체를 압축파일의 `Code.gs`로 교체합니다.
3. 편집기 왼쪽 **파일 + → HTML**에서 이름을 **Index**로 지정하고, 기본 내용 전체를 `Index.html`의 내용으로 교체합니다. 파일명은 대문자 I로 시작하는 `Index`입니다.
4. 상단 실행 함수에서 **setupTeacherSign_**을 선택하고 실행합니다. Google Drive·Sheets 권한을 승인하고 실행 로그의 **관리자 연결키**를 따로 보관합니다. 이 함수는 편집기에서만 실행하며 학교 데이터 전용 폴더를 만듭니다.
5. **배포 → 새 배포 → 웹 앱**을 선택합니다. **실행 사용자: 나**, **액세스 권한: 모든 사용자**로 배포합니다. 일반 참여자가 Google 로그인 없이 접근할 수 있는 설정을 사용합니다. 학교 Google Workspace 정책이 공개 웹앱을 허용하지 않으면 조직 관리자 확인이 필요합니다.
6. 발급된 **/exec 주소**를 엽니다. 처음에는 학교 관리자 최초 설정 화면이 나옵니다. 학교 이름·연결키·관리자 아이디·12자 이상 암호를 입력합니다.
7. 학교 관리자 아이디·암호로 로그인합니다. 교직원 명단을 올리고 연수를 등록한 다음 **링크 공유**에서 QR을 배포합니다. 참여자는 학교 관리자·Vercel 계정 없이 QR로 서명합니다.

`appsscript.json`은 V8·서울 시간대·Drive/Sheets 권한을 명시한 선택 파일입니다. 프로젝트 설정에서 매니페스트 표시를 켠 경우 같은 내용으로 설정할 수 있습니다. 일반 교사는 npm/Node 설치 없이 위 파일을 붙여넣으면 됩니다.

## 기존 v5 시험 설치를 전환

새 프로젝트를 만들지 않고 기존 **동일 GAS 프로젝트**의 `Code.gs`를 교체하고 **Index HTML**을 추가합니다. 기존 스크립트 속성·저장 폴더·파일 ID를 유지합니다. **배포 관리 → 기존 웹앱 수정 → 새 버전**으로 배포하여 /exec 주소를 유지합니다. 관리자 계정과 자료는 그대로이며 계정을 새로 만들 필요가 없습니다. 암호 검증은 기존 v5 scrypt 형식과 호환됩니다.

기존 Vercel 링크와 QR은 사용하지 말고 GAS /exec 주소에서 QR을 다시 발급합니다. 기존 v4 자료를 v5로 자동 이전하지는 않습니다. v4 운영 프로젝트는 따로 보관하고 새 v5 프로젝트로 시작합니다.

## 업데이트

관리자로 로그인하고 **서버 연결 설정 → 프로그램 업데이트**에서 현재 화면·GAS와 GitHub 최신 버전을 비교합니다. 새 버전이 있으면 **GAS 설치 ZIP 다운로드**로 파일을 받습니다. **Code.gs와 Index HTML을 함께 교체**하고 기존 배포를 **새 버전**으로 수정합니다. 스크립트 속성이나 Drive 파일을 삭제하지 않습니다. 업데이트는 자동 설치하지 않습니다.

## 확인할 항목

- /exec에서 JSON 대신 학교 최초 설정 또는 로그인 화면이 열립니다. 서버 상태 JSON은 /exec?action=healthCheck 입니다.
- 관리자가 로그인해야 연수·명단·서명을 관리할 수 있습니다. 새로고침하거나 창을 닫으면 다시 로그인합니다.
- QR은 해당 학교의 /exec 주소로 연결됩니다. 참여자는 관리자 로그인 없이 자신의 서명을 보냅니다.
- 로그아웃 버튼을 누르면 처리 표시가 나오고 서버 세션이 폐기됩니다. 30분간 관리 요청이 없거나 8시간이 지나도 세션이 종료됩니다.
- 실제 교직원 명단을 쓰기 전 가상 연수·가상 이름으로 저장·새로고침 후 조회·QR 서명·동시 서명을 시험합니다. Google의 실행/저장 할당량은 각 학교 계정에 적용됩니다.
