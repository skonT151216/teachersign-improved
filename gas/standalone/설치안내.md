# 교직원 연수 등록부 · GAS 단독 설치 (GAS v5.2.1 / 화면 v5.2.1)

각 학교 담당자의 GAS /exec와 Google Drive에서 독립 실행합니다. 공용 도메인에서도 해당 학교 GAS 주소를 연결해 같은 계정·자료를 사용할 수 있습니다. /exec 이용자는 공용 사이트를 따로 설치하거나 Vercel에 로그인할 필요가 없습니다.

## 새 학교에 설치

**v4를 쓰던 학교는 아래 새 설치 절차만 진행하면 기존 연수가 보이지 않을 수 있습니다.** 먼저 압축파일의 [v4자료이전.md](v4자료이전.md)를 읽고 기존 JSON·서명 시트를 확인해 이전하세요. 원본과 현재 파일을 보존하고 복사본을 연결합니다. v5에 새 자료가 있으면 덮어쓰지 않습니다.

1. GitHub 최신 릴리스의 `TeacherSign-GAS.zip`을 내려받아 압축을 풉니다.
2. 학교 담당자의 Google 계정으로 https://script.google.com 에서 **새 프로젝트**를 만듭니다. 기본 `Code.gs` 내용 전체를 압축파일의 `Code.gs`로 교체합니다.
3. 편집기 왼쪽 **파일 + → HTML**에서 이름을 **Index**로 지정하고, 기본 내용 전체를 `Index.html`의 내용으로 교체합니다. 파일명은 대문자 I로 시작하는 `Index`입니다.
4. **저장**한 뒤 상단 실행 함수에서 **setupTeacherSign**(끝에 밑줄 없음)을 선택하고 실행합니다. Google Drive·Sheets·설치 계정 확인 권한을 승인하고 실행 로그의 **관리자 연결키**를 따로 보관합니다. 설치 담당자가 편집기에서 실행하며 학교 데이터 전용 폴더를 만듭니다. 익명 웹앱 방문자의 호출은 거절하고 연결키를 웹 응답으로 반환하지 않습니다.
5. **배포 → 새 배포 → 웹 앱**을 선택합니다. **실행 사용자: 나**, **액세스 권한: 모든 사용자**로 배포합니다. 일반 참여자가 Google 로그인 없이 접근할 수 있는 설정을 사용합니다. 학교 Google Workspace 정책이 공개 웹앱을 허용하지 않으면 조직 관리자 확인이 필요합니다.
6. 발급된 **/exec 주소**를 엽니다. 처음에는 학교 관리자 최초 설정 화면이 나옵니다. 학교 이름·연결키·관리자 아이디·12자 이상 암호를 입력합니다.
7. 학교 관리자 아이디·암호로 로그인합니다. 교직원 명단을 올리고 연수를 등록한 다음 **링크 공유**에서 QR을 배포합니다. 참여자는 학교 관리자·Vercel 계정 없이 QR로 서명합니다.

`appsscript.json`은 V8·서울 시간대·Drive/Sheets·설치 계정 확인 권한을 명시한 선택 파일입니다. 프로젝트 설정에서 매니페스트 표시를 켠 경우 같은 내용으로 설정할 수 있습니다. 일반 교사는 npm/Node 설치 없이 위 파일을 붙여넣으면 됩니다.

## 설치 함수가 목록에 없을 때

v5.1.0에서 `setupTeacherSign_`이 선택 목록에 보이지 않으면 최신 ZIP의 **Code.gs와 Index.html**로 교체하고 저장합니다. 상단에서 **setupTeacherSign**을 선택합니다. 목록이 갱신되지 않으면 저장 완료 후 편집기를 새로고침합니다.

`appsscript.json`에 `oauthScopes`를 직접 지정했다면 ZIP의 최신 매니페스트도 반영합니다. 설치 계정 확인을 위해 `https://www.googleapis.com/auth/userinfo.email`이 필요합니다. 자동 권한 설정을 사용하면 수동 추가는 필요하지 않습니다. 기존 스크립트 속성·Drive 파일·계정은 삭제하지 않습니다.

## 기존 v5 시험 설치를 전환

새 프로젝트를 만들지 않고 기존 **동일 GAS 프로젝트**의 `Code.gs`를 교체하고 **Index HTML**을 추가합니다. 기존 스크립트 속성·저장 폴더·파일 ID를 유지합니다. **배포 관리 → 기존 웹앱 수정 → 새 버전**으로 배포하여 /exec 주소를 유지합니다. 관리자 계정과 자료는 그대로이며 계정을 새로 만들 필요가 없습니다. 암호 검증은 기존 v5 scrypt 형식과 호환됩니다.

기존 Vercel 링크와 QR은 사용하지 말고 GAS /exec 주소에서 QR을 다시 발급합니다. 기존 v4 자료는 [v4 자료 이전 안내](v4자료이전.md)에 따라 담당자가 원본과 개수를 확인하고 이전합니다. `inspectTeacherSignLegacyData` → `previewTeacherSignMigration` → `migrateTeacherSignLegacyData`를 설치 담당자가 편집기에서 실행하며, 이름만으로 파일을 자동 선택하지 않습니다.

## 업데이트

관리자로 로그인하고 **서버 연결 설정 → 프로그램 업데이트**에서 현재 화면·GAS와 GitHub 최신 버전을 비교합니다. 새 버전이 있으면 **GAS 설치 ZIP 다운로드**로 파일을 받습니다. **Code.gs와 Index HTML을 함께 교체**하고 기존 배포를 **새 버전**으로 수정합니다. 스크립트 속성이나 Drive 파일을 삭제하지 않습니다. 업데이트는 자동 설치하지 않습니다.

## 확인할 항목

- /exec에서 JSON 대신 학교 최초 설정 또는 로그인 화면이 열립니다. 서버 상태 JSON은 /exec?action=healthCheck 입니다.
- 관리자가 로그인해야 연수·명단·서명을 관리할 수 있습니다. 새로고침하거나 창을 닫으면 다시 로그인합니다.
- QR은 해당 학교의 /exec 주소로 연결됩니다. 참여자는 관리자 로그인 없이 자신의 서명을 보냅니다.
- 로그아웃 버튼을 누르면 처리 표시가 나오고 서버 세션이 폐기됩니다. 30분간 관리 요청이 없거나 8시간이 지나도 세션이 종료됩니다.
- 실제 교직원 명단을 쓰기 전 가상 연수·가상 이름으로 저장·새로고침 후 조회·QR 서명·동시 서명을 시험합니다. Google의 실행/저장 할당량은 각 학교 계정에 적용됩니다.

## 공용 사이트와 업데이트 범위

공용 도메인의 v4 화면은 v5 GAS와 요청 방식이 달라 연결되지 않습니다. 공용 사이트 운영자가 TeacherSign-Site.zip으로 화면을 갱신해야 합니다. 학교별 /exec 이용자는 TeacherSign-GAS.zip의 Code.gs와 Index HTML을 설치하면 됩니다. 공용 사이트에서 QR을 발급하면 도메인 주소와 해당 학교 GAS 주소가 포함됩니다.

요청 버전 1을 유지하는 서버 처리 수정은 GAS만 갱신할 수 있습니다. 화면 수정에는 Index HTML 갱신이 필요하고, 공용 사이트 화면도 바꿀 때에는 운영자가 사이트를 갱신합니다. 요청 버전이 달라지면 화면에서 호환 오류를 안내하며 양쪽을 함께 맞춰야 합니다.
